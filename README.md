# frameprot

Frame CSV/TSV prot tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/frameprot/

## Install / run

```bash
git clone https://github.com/theworker02/frameprot.git
cd frameprot
node src/cli.js
node --test
```
